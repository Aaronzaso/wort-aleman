# Wort

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Elegida para este encargo: HTML, CSS y JavaScript nativos, sin dependencias de ejecución. PWA estática para GitHub Pages. Se ofreció elección de tecnología; el usuario no expresó una preferencia.

## Users

Hispanohablantes que comienzan a aprender alemán desde cero y estudian desde su celular.

## Product Purpose

Practicar alemán con explicaciones en español, ejemplos cotidianos, recuperación activa y repasos espaciados. El usuario pidió crear su repositorio de GitHub.

## Operating Context

Sesiones breves en Android o iPhone. El progreso se conserva en el navegador del dispositivo. No requiere cuenta, servidor ni claves de servicios.

## Capabilities and Constraints

Ocho lecciones iniciales, 64 tarjetas, 48 ejercicios de comprensión y escritura, tarjetas de repaso, audio del dispositivo y progreso local. El audio depende de una voz alemana disponible. Contenido inicial orientativo A0–A1; no equivale a un curso completo ni a una certificación. El usuario autorizó expresamente repositorio y app públicos con enlace para celular.

## Evidence on Hand

El usuario corrigió expresamente el idioma a alemán desde cero. El enlace compartido se titula «Práctica de pronombres alemanes», pero el cuerpo no es accesible públicamente.

## Product Principles

- Explicar desde el español sin equiparar sonidos que son diferentes.
- Practicar antes de revelar respuestas.
- Repetir lo que cuesta y conservar el progreso real.
- Mantener los controles legibles y cómodos en celular.
